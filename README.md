# TACTIX — Public court demo

A free, standalone 3D padel tactics playground. Arabic and English. No registration, backend connection, payments or multiplayer. Each visitor has an independent court saved in their own browser.

Try it: https://abdra7.github.io/tactix-demo/

Move players and the ball, draw trajectories, adjust lob height, switch camera angles, and undo edits. The supplied TACTIX logo is used unchanged. Clear demo data using the control below the court.

This repository contains built static demo assets only. GitHub Pages publishes the main branch root. It is a project demonstration, not a hosted commercial SaaS service.
